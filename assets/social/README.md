# Social Assets

Social-media assets for AI Tool Vault.

## Brand

- Primary accent: electric blue → violet gradient
- Dark background: `#080A0F`
- Primary text: white
- Recommended font: Inter or Manrope
- Short-form canvas: 1080 × 1920 px (9:16)

## Usage

Use the logo and icon consistently across TikTok, Instagram, YouTube and other social profiles. Keep clear space around the mark and do not distort the SVG files.
