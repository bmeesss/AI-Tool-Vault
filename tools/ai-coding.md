# AI Coding Tools

## GitHub Copilot

- **Official website:** https://github.com/features/copilot
- **Category:** AI Coding
- **Pricing model:** Free + paid plans
- **Best application:** Code completion, coding chat, agents and code review
- **Description:** GitHub's AI coding assistant integrated into GitHub and major development environments.
- **Why useful:** It can assist directly inside the developer workflow and connect coding assistance with repositories, agents and GitHub tooling.
- **Tags:** `coding` `github` `copilot` `code-completion` `agents`

## Cursor

- **Official website:** https://cursor.com/
- **Category:** AI Coding
- **Pricing model:** Free + paid plans
- **Best application:** AI-assisted software development inside an editor
- **Description:** An AI-first code editor built around conversational coding, codebase context and agent-style development workflows.
- **Why useful:** It is designed around AI-assisted editing rather than adding AI as a small extension to a traditional editor.
- **Tags:** `coding` `ide` `code-editor` `agents` `developer-tools`

## Replit

- **Official website:** https://replit.com/
- **Category:** AI Coding
- **Pricing model:** Free + paid plans
- **Best application:** Building, testing and deploying apps from a browser
- **Description:** A browser-based development platform with AI-assisted coding and integrated tools for creating and deploying applications.
- **Why useful:** It lowers the setup barrier because development, hosting and collaboration can happen in one environment.
- **Tags:** `coding` `web-development` `deployment` `browser-ide` `app-builder`
