## Tool entry standard

Every tool entry contains:

- Name
- Official website
- Category
- Pricing model
- Best application
- Description
- Why it is useful
- Tags

Pricing and feature information is intentionally kept at the plan-model level where details change frequently. Always check the official website for current prices.
