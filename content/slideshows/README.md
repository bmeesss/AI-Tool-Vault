## Format

Each slideshow contains:

- Hook
- Slide-by-slide copy
- Featured tools
- CTA
- Caption
- Suggested tags
- Visual direction

The slideshows are designed for 1080x1920 vertical content and can be recreated in Canva or another design tool.
