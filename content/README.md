# AI Tool Vault Content

This directory contains content created for AI Tool Vault.

## Content Types

- TikTok slideshows
- Short-form video concepts
- Scripts
- Hooks
- Captions
- Tool discoveries
- Educational content

## Structure

Content is organized separately from the AI tool database.

The `tools/` directory contains information about AI tools.

The `content/` directory contains content created around those tools.

## Content Standards

Content should be:

- Clear
- Useful
- Accurate
- Easy to understand
- Visually consistent with the AI Tool Vault brand

Tool claims, pricing and features should be verified before publishing.
