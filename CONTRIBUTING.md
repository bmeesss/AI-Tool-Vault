# Contributing to AI Tool Vault

Thanks for helping improve AI Tool Vault.

## Adding a tool

Before submitting a tool, make sure it:

1. Is an actual AI-powered product or service.
2. Has a working official website.
3. Provides a clear use case.
4. Is useful enough to recommend.
5. Is not simply a duplicate of an existing entry.

## Tool submission

When suggesting a tool, include:

- Tool name
- Official website
- Category
- Short description
- Main use case
- Free or paid status
- Why it is worth adding

## Quality

AI Tool Vault prioritizes useful tools over large numbers of tools.

A smaller collection of high-quality tools is better than a huge collection of mediocre ones.

## Updates

If pricing, features or availability change, open an issue or submit an update.

Please use official sources whenever possible.
